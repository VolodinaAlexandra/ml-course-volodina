# House Prices — описание данных

Источник: [Kaggle House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/overview). Локальные файлы `train.csv` и `test.csv` уже были предоставлены в папке `data/`.

| Файл | Строк | Столбцов | Целевая переменная |
|---|---:|---:|---|
| `train.csv` | 1460 | 81 | `SalePrice` |
| `test.csv` | 1459 | 80 | отсутствует |

Из 80 столбцов без цели один — идентификатор `Id`; 79 — характеристики дома. В обучающем CSV 36 числовых и 43 категориальных объясняющих столбца. `Id` не используется как признак.

`SalePrice` в долларах: минимум **34 900**, максимум **755 000**, среднее **180 921,20**, медиана **163 000**. Асимметрия по Pandas — **1,883**, эксцесс — **6,536**. Правый хвост объясняет решение обучать модели на `log1p(SalePrice)` и возвращать прогноз в доллары через `expm1`.

В `train.csv` пропуски есть в **19 столбцах**. Наиболее частые: `PoolQC` — 1453, `MiscFeature` — 1406, `Alley` — 1369, `Fence` — 1179, `MasVnrType` — 872, `FireplaceQu` — 690, `LotFrontage` — 259. Для характеристик отсутствующего объекта применяется категория `None` или 0; `LotFrontage` заполняется медианой района по обучающей части.

В ноутбуке отложенная выборка выделена из `train.csv`. Файл `test.csv` используется только для демонстрации предсказаний: без истинной `SalePrice` он не позволяет вычислить RMSE или R².
